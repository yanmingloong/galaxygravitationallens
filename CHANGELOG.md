## [Unreleased]

### Added

- **Orchestration layer: `Pipeline` + `Stage`, `gl.analyze`, and `gl.mock`** (2026-11-03): a thin auto-mode layer over the pluggable components. `api.pipeline` provides `Stage` (one named component call) + `Pipeline` (ordered stages sharing a `ctx` dict), with `run(start/stop/only)` for full-auto / partial / range runs; every stage stays individually callable (manual mode). `api.analysis.analyze` (exposed as `gl.analyze`) is the one-call post-fit summary: weighted posterior of the six mass parameters, derived quantities (beta_z / M* / f_dm at median / theta_E / gamma_tot), a prior-edge check (2.5/97.5% within 1% of the bound), and the corner plot. `mock_pipeline.orchestrate.build_mock_pipeline` (exposed as `gl.mock`) wires the mock-closure chain select -> pick -> truth -> render -> make_arc -> mock_fit -> closure into a `Pipeline`, each stage a thin wrapper over the existing `selection` / `skirt` / `lensing` / `validation` modules with clear pre-flight guards (the heavy stages need TNG data + SKIRT binary). Regression: verify_pipeline, verify_mock_orchestrate. Note: `analyze` computes f_dm at the median parameters (one call) rather than `Result.f_dm`'s O(N) per-sample loop, which re-fits the halo MGE per sample and takes minutes for thousands of samples.

- **Lens identification layer: `gl.identify`** (2026-11-03): `sample_library.identify` adds the missing "identify" link — from a catalog row it infers lens type (disk/elliptical via `lens_type_label` + `n_sersic` + `B_D_ratio`) and lens constraint (imaging/positions via `n_images` + a known-quad name list), then maps to modeling modules + a recipe template (`LensPlan`). `gl.identify(name)` is the facade entry; `write_recipe(plan, params)` copies the template + overrides keys (dot-nested supported) to emit a runnable YAML. Anchors: J2141 -> disk/jampy_kdc, J1331 -> quad/positions, a DEV row -> elliptical/jampy. Regression: verify_identify.

- **Elliptical sample-library upgrade** (2026-11-03): `sample_library.enrich_elliptical` assembles a modelable elliptical table `modeling_input_elliptical_modeling.csv` (14 lenses) from the Dinos SLACS params (3 complete: zl/zs/sigma/theta_E/gamma/Re/n/q/PA) + the KCWI kinematics table (14 sigma_ap/Re/q). `data_complete` marks 3 "full" (theta_E/gamma present) vs 11 "sigma_only" (theta_E/gamma still missing — need the SLACS Einstein-radius literature). `identify._lookup` now prefers DEV-tagged rows, so J1630/J1402/J2303/J0037/J0330 identify as elliptical instead of the disk default. Regression: verify_identify (14 DEV rows asserted).

- **Image-shape identification: `gl.identify_from_image`** (2026-11-03): `sample_library.morphology` measures light concentration C = 5*log10(r80/r20) + axis ratio q directly from a FITS image (numpy/astropy only), as an image fallback when catalog morphology is missing/unreliable. Calibrated on real data: J2141 disk C=1.58 vs J1630 elliptical C=4.21 (thresholds C<3.1 disk, C>3.4 elliptical); q is dragged round by the arc+PSF (both ~0.89) so it is auxiliary only. `gl.identify_from_image(fits_path)` returns a LensPlan. Regression: verify_morphology.

- **Mock-closure end-to-end validation + light-MGE component** (2026-11-03): `gl.mock`'s truth / render / arc were validated against real TNG particles + SKIRT v9.0 for subhalo 348489. truth reproduces the MF ground truth exactly (M*=8.90e10, c_-2=5.55 vs 5.554, v_vir=218, gamma=1.53, q_h=0.736, f_dm 5/10 kpc to 4 decimals); render runs TNG -> SKIRT (16.8s) -> fake HST -> data/noise/psf end-to-end; arc's build_lens_galaxy / einstein_radius (0.609") / make_arc reproduce the M* self-check to 1.000. New `mock_pipeline.lensing.mge.fit_light_mge` (extracted from mf1a_mge.py) fills the arc front-end gap (light MGE from the mock image, mgefit; reproduces the MF 348489 MGE digit-for-digit). Added `configs/fit/j2141_mock.yaml` + `j2141_mock_mge.csv` (mge_csv stellar template + particle v_rms); closure stage aligned (lg_ml ml_to_dyn bridge + arcsec apertures). Remaining: fit + closure end-to-end need a real Nautilus run (hours); the beta_z anisotropy convention vs MF needs reconciling.

- **Elliptical-lens aperture dispersion (sigma_ap)** (2026-11-01): `JampyEngine` now supports a single luminosity-weighted aperture velocity dispersion sigma_ap (the elliptical-lens kinematic observable), computed via `jam.axi.proj`'s `pixsize` + `sigmapsf` convolution. `KinData` gained `aperture_radius`/`aperture_vrms`/`aperture_vrms_err`/`kin_psf_sigma`; the radial `v_rms` profile may be omitted. `config_loader` reads the aperture fields; new template `configs/fit/elliptical_slacs_example.yaml` (template, not yet end-to-end validated). Regression: verify_ellip_aperture (3" sigma_ap = 168.8 km/s for the J2141 B7 model). Also added `stellar_mge_ellip` (single-Sersic no-disk stellar template for ellipticals, `stellar_template type: ellip`) and the first real elliptical recipe `configs/fit/j1630_ellip.yaml` (SDSS J1630+4520, a SLACS slow rotator: sigma_ap = 267 km/s in a Re aperture). Regression: verify_j1630 (config + sigma_ap mechanism). bulge_i0 = 232 counts/s/px (I_e=0.1083 from the engine's own single-Sersic subtraction, I(0)=I_e*exp(b_n); NOTE `al.lp.Sersic.intensity` is I_e, not the central surface brightness -- off by exp(b_n)=2141 for n=4). The sigma_ap at prior-centre parameters is ~100 km/s vs 267 because those parameters are too light (M(<Re) ~5.5e10 vs the ~1.3e11 Msun that sigma_e=267 implies) -- the cluster fit resolves it. Subtracting the elliptical galaxy light uses a new `subtract_stellar_light_sersic` (single Sersic n=4, structure fixed to SLACS_light_params, only intensity + centre free; `DataSpec.subtract_method: "sersic_single"`), because the B4 bulge+disk subtraction is hard-coded to the J2141 disk structure and does not apply to an elliptical lens. End-to-end smoke verified: load_dataset (sersic_single) -> assemble (13 params) -> Nautilus (n_live=20) runs clean.

- **B9 extraction: pixelized source + AGN point-source subtraction + sky-RMS noise** (2026-11-01): `lensfit.models.source.pixelized` (`PixelizedSource`, PyAutoLens Pixelization + RectangularUniform mesh + Constant regularization; `n_source` = mesh pixel count vs `n_free_params` = regularization coefficient, so `nu_img = n_unmasked - n_source` subtracts the 225 mesh pixels). `lensfit.lens.subtract.subtract_stellar_light_mge_agn` (literature MGE + PSF-shaped AGN point source, joint least-squares; the B9 recipe that drops the subtraction reduced chi2 from 2.58 to 1.11). `lensfit.lens.rescale.estimate_sky_noise` (direct sky-RMS, bypassing the KAI drizzle weight-map pitfall). `SourceModel.n_source` defaults to `n_free_params` (parametric sources unchanged). Regression: verify_lensfit_b9 (sky RMS recovered, subtraction reduced chi2 1.11 reproduced, pixelized 7 explicit params / n_source 225). Also wired the B9 path into the facade: `api.dataset` gained `subtract_method="mge_agn"` (sky-RMS noise + MGE/AGN-point-source subtraction on the native grid, no separate noise FITS), `DataSpec` gained `mge_params_path`/`badmask_path`/`psf_sigma_px`/`position_angle_deg`, and `PriorSet.ml_img_spec` adds an optional Gaussian M/L prior (B9 K'-band N(0.8, 0.3)). New recipe `configs/fit/j2141_b9_kband_pixelized.yaml` (pixelized source + mge_agn subtraction + K'-band stellar template). Also extracted the B9 K'-band stellar-template calibration as `stellar_mge_kband` (a two-sided bridge: `StellarTemplate.calibration` = the dynamics `SURF_FACTOR` bridge in Msun/pc^2, `calibration_img` = the Sigma_crit-normalised imaging bridge; `stellar_template type: mge_csv` in the config loader). Regression: verify_b9_recipe. New `docs/components_reference.md` (+`_zh`): pluggable-component + configurable-parameter index.

- **Mock-closure validation layer + truth extension + strong-lens arc synthesis** (2026-10-27): `mock_pipeline.truth` gained `particles` (HDF5 particle loading in physical units + inertia-tensor mock-frame alignment), `fdm` (dark-matter fraction ground truth, spherical + cylindrical edge-on apertures), `anisotropy` (`beta_z = 1 - sigma_z^2/sigma_R^2` from the velocity tensor), and `halo` (gNFW fit to DM particles -> v_vir/c_-2/gamma/q_h, reusing the lensfit `zeta`/`halo_cosmo` parametrization). New `mock_pipeline.lensing` (`arc` + `dataset`): `build_lens_galaxy` / `einstein_radius` / `make_arc` (strong-lens arc ray-tracing against the true mass model) and `scale_arc` / `merge_arc`. New `lensfit.validation` (mock closure): `fdm` (spherical + cylindrical apertures), `bias`, `corner` (weighted corner + truth overlay), `prior_sensitivity` (M/L prior-centre reweighting + ESS), `diagnostics` (m=2 Fourier bar test), `closure` (fit samples -> f_dm -> truth bias). `lensfit.dynamics.jampy` gained a `beta_z`-direct anisotropy option (`anisotropy_param`, `beta_cyl_beta_z`, `beta_z_to_ratio`/`ratio_to_beta_z`) matching the MF-series convention; `PipelineConfig.dynamics_anisotropy` selects it. Regressions anchor on 348489 (f_dm spherical 0.695 / cylindrical 0.797, beta_z +0.40, halo v_vir 218 / c_-2 5.55 / gamma 1.53 / q_h 0.74, theta_E 0.609 arcsec) with `skip-if-missing` guards.

- **Componentized `lensfit` core layer + facade `api` layer** (2026-10-21, refinement stages 1-4): rebuilt the fitting engine as pluggable model components + a config-driven assembler. `lensfit.structures` (Geometry/KinData/Calibration/PriorSet/PipelineConfig); `lensfit.models` (MassComponent/SourceModel/DynamicsEngine ABCs; `dm.gnfw_virial` Wyithe-2001 gNFW in v_vir/c_-2/gamma/q_h + `gnfw_virial_profile`, `stellar.mge_const_ml`, `source.single_sersic`); `lensfit.dynamics.jampy` (Cappellari 2020, anisotropy as explicit `ratio = sqrt(1-beta_z)`); `lensfit.fit.joint` (JointAnalysis, log L = -0.5*(chi2_img/nu_img + chi2_dyn/nu_dyn)); `lensfit.pipeline.assemble` (component registry, zero physics). New facade `galaxylens.api` (config_loader / dataset / search(Nautilus) / result / derived / plotting.corner / facade); `result.py` reads beta_z / c_-2 / gamma / v_vir / q_h / M* / f_dm as weighted medians directly off samples.csv. First recipe `configs/fit/j2141_barnabe.yaml`; `gl.fit()` reproduces B7 on the Loong cluster (job 128011: log Z = -8.04, all parameters within +/-2.5% of B7). Updated `lensfit.lens.models` from `gNFWMCRLudlow` (B4) to `GNFWVirialVelocity`. Regressions: verify_lensfit_joint_b7 / verify_api / verify_lensfit_lens / verify_fit_smoke.
- **Second component set + pointwise (coordinate-level) fitting** (2026-10-21, stage 5): `lensfit.models.dm.nfw` (spherical v200+c200), `lensfit.models.stellar.mge_radial_ml` (radial M/L, luminous tracer != mass), `lensfit.dynamics.jampy_kdc` (kappa counter-rotating core + direct beta_z + PSF convolution), `lensfit.lens.scale_free` (quad-image pointwise re-projection). Abstracted `lensfit.fit.constraints.LensingConstraint` (ImagingConstraint pixel-level / MeinConstraint single-value Einstein mass / scale-free quad-image) so the pipeline supports both pixel-level (B-series arcs) and coordinate-level (D-series quads) fitting; added `gl.fit_positions` / `gl.fit_mein`. Regressions: verify_lensfit_d1 / verify_lensfit_d5 / verify_facade_point.
- **Cross-platform + slurm backend + CI** (2026-10-21/22, stage 6): `api.search` slurm backend (`slurm_script` + `submit_slurm`, template matches the verified `examples/j2141_b7.slurm`), `SearchSpec.workdir/mem`, `api.runner` CLI (forced `backend=local`), `.github/workflows/ci.yml` (Windows+Linux core/pure-python, Linux-only full stack), portable test paths, README cross-platform declarations. Disabled autofit's built-in anesthetic corner plot on headless runs (`_disable_autofit_corner_plot`) -- the repo's own weighted corner reads samples.csv with the Agg backend.

- `mock_pipeline` J1331 support + KDC/roll/single-scale (2026-10-20): `truth.major_axis_angle` (eigen-decomposition roll, removes the +/-90 deg ambiguity of the 0.5*arctan2 formula), `truth.counter_rotation_angle` (core-vs-outer angular-momentum KDC test, ~180 deg hard criterion; a mild reversed rotation in a hot bulge is NOT a KDC), `skirt.single_scale_normalize` + `skirt.make_mock_dataset` (single photometric scale preserving the SED colour ratio for multi-band joint fitting + data/noise/psf fitting-ready FITS; noise map generated AFTER crop/pad so zero-padding never contaminates the border), `lensfit.psf.moffat_mge_psf` (four-Gaussian Moffat MGE PSF, Trick+2016 Table 2), and `selection.config.J1331` (second built-in target: snap90, M* in [1e11, 3e11], sigma >= 190, incl 70 deg, F435W/F814W).
- Data-fied the skirt observation config (2026-10-17): new `BandConfig`/`MockObsConfig` (band+instrument name+pixel scale+noise+peak / geometry); `write_ski` now takes a `BandConfig`+`MockObsConfig` (no more hard-coded BANDS dict — same filter on a different instrument, e.g. WFPC2 F814W, is expressible); `make_fake_hst` takes a `BandConfig` (dropped F814W-specific PX_HST/SIGMA/J_PEAK). `TargetConfig` gains an `obs` field. `snap_to_a` now raises on unknown snapshots instead of silently returning a=1.0.
- Renewed `notebooks/mock_pipeline_demo.py` into a full tutorial (8 sections; offline sections fully runnable, heavy sections gated on TNG key / particle data / SKIRT binary).
- Made `read_api_key` silent on import; the "key not found" hint now prints on-demand in the download/request paths.
- Added `incl` field to `TargetConfig` + `read_api_key()` (2026-10-17): disk inclination moved into target config (J2141=78.5 deg, J1331=70 deg); `skirt.render.write_ski` reads it from target.incl. TNG API key now read from env `TNG_API_KEY` or the `~/.tng_api_key` file (no key hard-coded), with a one-time hint pointing to docs/mock_pipeline.md; `get()`/`download_cutout()` fail fast without a key.
- `mock_pipeline.truth` module (2026-10-14): ground-truth computation — kinematics (circularity → f_disk/B_D/disk axis/thickness), measures (half-mass radius / projected-ellipticity covariance convention / intrinsic axis ratios / extinction), cosmology (Planck 2015 distances + SIS theta_E + cosmic time + TNG unit conversions), with regression tests (348489 f_disk=0.643, B/D=0.55 reproduced); fixed tng_to_skirt H0_GYR typo (0.06774→0.06928).
- `mock_pipeline.selection` module (2026-10-14): TNG disk-lens analog selection — scan / filter (L1 criteria as data) / merger (L2 mpb.hdf5 main-branch mass-jump) / download (3-field & all-field merged) / verify (L3 disk_kinematics) / catalog (L3→catalog auto-assembly) / run (--target end-to-end). Selection criteria live in a SelectionCriteria dataclass; switching target needs no code change.

- `mock_pipeline.skirt` module (2026-10-14): SKIRT radiative transfer — convert (TNG particles → .dat, inertia-tensor alignment, no legacy L_hat) / render (.ski generation + skirt run, SKIRT_BIN env var) / imaging (fake HST + extinction map). Fixed write_dust ``a``-parameter bug and vectorized cosmic_time.
- **Elliptical-mock sigma_ap ground truth** (2026-11-02): `mock_pipeline.truth.aperture.sigma_ap` (mass-weighted dispersion `sqrt(<v_los^2> - <v_los>^2)`, circular sky aperture, no PSF convolution; the truth counterpart to the JampyEngine sigma_ap observable). Regression: `tests/test_truth_aperture.py`. Plus the mock<->fit contract regression `tests/test_mock_api_contract.py` (mock data/noise/psf FITS load through `api.dataset.load_dataset` unchanged).

### Fixed

- **Multiprocessing pickle of the joint analysis** (2026-11-02): `fit/joint.py` `_JointAnalysis` was a function-local class, so `number_of_cores > 1` failed to pickle (`Can't get local object`). It now carries a stable module path (`__module__`/`__qualname__`) and is registered in the module namespace; picklable on Linux (fork). Regression: `tests/test_joint_pickle.py`.
- **Full test-suite collection blocked by photutils** (2026-11-02): `tests/test_psf_selection.py` imported photutils transitively at collection without a skip guard. Added `pytest.importorskip("photutils")`.
- **Closure calibration convention documented** (2026-11-02): `validation.closure.sample_f_dm` docstring now spells out the two calib conventions (F814W `calib=1` + Sigma_crit bridge in `lg_ml`; K'-band `calib=dyn-bridge` + `lg_ml=log10 M/L`) and forbids mixing them.
